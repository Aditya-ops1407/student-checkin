About the project

Student Mental Health Risk Prediction Using Machine Learning is a BCA project at Babasaheb Bhimrao Ambedkar University (Satellite Centre, Amethi).

Aim

To show the full machine-learning pipeline on a real problem: data cleaning, preprocessing, model comparison, evaluation and a working web application. The system is a screening aid. It does not diagnose.

Built with

Python, pandas, scikit-learn (Logistic Regression, Decision Tree, Random Forest), Flask, and plain HTML and CSS.

Data

A public student depression survey of 4,461 students (after removing duplicates). See The model for how it was used and what was excluded and why.
